If something goes wrong

The three problems almost everyone hits, and the fix for each.

Play Protect says the app is not recognised

Play Protect flags every app installed from outside the Play Store, including ones that are perfectly fine. Choose Install anyway. If you want certainty first, verify the SHA-256 checksum above against your downloaded file — a match means the file is byte-for-byte what we published.

The install button is greyed out

Your Android version needs permission for the specific app doing the install. Go to Settings, then Apps, then find your browser or file manager, then Install unknown apps, and allow it. Return to the file and try again.

“App not installed” appears at the end

Usually one of three things: an older copy of the app is already installed and needs to be removed first, the download was interrupted and the file is incomplete, or storage is full. Uninstall the old version, clear some space, and download the file again.

How do updates work without the Play Store?

The app checks for a newer version on launch and tells you when one is available. You return to this page, download the latest APK and install it over the existing app. Your account, balance and history are untouched by an update.

One warning worth repeating. This page is the only place we publish the app. Any APK for EarnKit found on a file-sharing site, a messaging group or a mirror download site is modified, and a modified build of a money app is modified for exactly one reason.
